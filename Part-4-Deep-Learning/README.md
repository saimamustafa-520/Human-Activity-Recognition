# Human Activity Recognition (HAR)

This project classifies 6 human activities using raw accelerometer and gyroscope data from smartphones.

## Models Tested
- RNN
- LSTM
- GRU

## Results
- RNN Accuracy: 36.85%
- LSTM Accuracy: 21.75%
- GRU Accuracy: 82.94%

## How to Run
1. Run the Python notebook/script.
2. The dataset will be downloaded automatically.
3. Models will train and show accuracy and confusion matrix.

## Notes
- Raw signals used, no feature engineering.
- GRU performs best on this dataset.
